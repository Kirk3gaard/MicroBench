Basecalling models and assemblers on the ZymoHMW mock

To check the quality of nanopore data with the ZymoHMW mock DNA. There are some serious improvements in raw read accuracy between the fast, hac sup, and now hyp models. However, for some reason the improved raw read accuracy of the hyp(er) accuracy model does not improve assemblies consistently for all of the organisms.
