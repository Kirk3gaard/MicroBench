MicroBench

Nanopore sequencing data for microbial genomics benchmarking — monocultures, mock communities and real metagenomes, basecalled with several dorado models, plus Hi-C for selected samples.

About the numbers

  • Reads and yield are the exact counts reported by ENA for each submitted file. The value shown for a dataset is from the sup (or modified-base) file.
  • N50 and read Q are computed from the BAM files. BAMs under 250 MB are read completely (exact values). Larger ones are estimated (marked ≈) from about 30 evenly spaced 1 MB slices of each BAM (typically 2,000–5,000 reads), fetched with HTTP range requests. Read Q is the median per-read mean quality. Checked against a full pass over one 600 MB BAM, the estimates were within 1%.
  • Basecalling settings (dorado version, full command line, models, GPU, flow cell, device and run date) are read directly from the BAM headers.
  • Library kit comes from the library_kit column in ENA_data_links.tsv.
  • File suffixes: sim = simplex reads, dup = duplex reads, mods = sup basecalls with 4mC/5mC/6mA modification tags (unaligned BAM), pod5 = raw signal archive.
